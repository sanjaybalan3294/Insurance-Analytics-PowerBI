# Insurance Analytics Dashboard – Power BI

## 📊 Project Overview

This project analyzes insurance data using Power BI to identify
customer, policy, premium, and claims-related insights.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Dashboard

The dashboard contains visualizations for:

- Customer demographics
- Policy types
- Premium analysis
- Claims analysis
- Policy status
- Customer age groups

## 🔍 Key Insights

- Property was one of the major policy categories.
- Customers aged 60+ represented a significant policyholder segment.
- Total claims exceeded ₹251M.
- The dashboard provides comparisons between claims and payments.
